# Meeting Notes

Executive summaries and action items from project meetings, kept close to the documentation they
affect. Each entry is a decision record for *process* (who does what, in what order) the way the
[ADRs](../adr/) are a decision record for *architecture* — short, dated, and written so a change to
the plan is traceable to the meeting that caused it.
