# Architecture Decision Records

Short, dated records of decisions that were genuinely weighed against an alternative — not a log of
every choice made. Format: Context, Decision, Consequences (including the costs accepted, not just
the benefits).

| [0002](0002-mocked-external-dependencies.md) | Mock every external dependency at the boundary |
| [0003](0003-gcp-target-architecture.md) | GCP as the reference deployment target |
| [0004](0004-java25-spring-boot4-runtime.md) | Java 25 and Spring Boot 4 as the uniform runtime target |
| [0005](0005-consolidated-react-frontend.md) | One React frontend stack for both customer and staff surfaces |
